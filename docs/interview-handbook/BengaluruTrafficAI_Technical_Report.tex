\begin{abstract}
This report provides a rigorous, repository-first technical audit, architectural analysis, and comprehensive interview preparation handbook for \textbf{BengaluruTrafficAI} (GitHub: \url{https://github.com/Kaushtubha/BengaluruTrafficAI}). Addressing severe urban bottleneck degradation at high-density intersections such as the Silk Board Junction in Bengaluru, India, the project implements an edge-to-cloud intelligent transportation system. The platform incorporates multi-class vehicle detection via YOLOv8, deterministic greedy multi-object tracking via Intersection-over-Union (IoU), monotonic displacement-based speed estimation, stop-line red light and wrong-side driving violation detection, proportional adaptive green-time allocation with emergency preemption, and an exploratory Random Forest congestion classifier. The user-facing ecosystem comprises an operations dashboard, an analytics reporting page, and a driver assistance portal built with React 18, Vite 5, Tailwind CSS, Recharts, and Zustand. This document details the mathematical, algorithmic, and architectural implementation of both the local computer-vision inference pipeline and the hosted cloud demonstration engine, accompanied by 60+ tiered technical interview questions, worked whiteboard exercises, and honest telemetry disclosures.
\end{abstract}

\section{Hardware Resource Utilization and Profiles}
\begin{itemize}[leftmargin=*]
    \item \textbf{Local Computer Vision Mode (\texttt{app.py})}:
    \begin{itemize}
        \item CPU Execution: Utilizes $\approx 65\%\text{--}85\%$ of a modern 4-core x86\_64 CPU when decoding 30\,FPS $1280 \times 720$ video with YOLOv8n.
        \item RAM Footprint: $\approx 1.2\text{--}1.8\,\text{GB}$ during active PyTorch model weights loading and OpenCV buffer decoding.
    \end{itemize}
    \item \textbf{Hosted Cloud Demonstration Mode (\texttt{app\_demo.py})}:
    \begin{itemize}
        \item CPU Execution: $< 2\%$ CPU utilization on Render container (pure mathematical operations and simulated stochastic steps).
        \item RAM Footprint: $\approx 65\text{--}85\,\text{MB}$, remaining safely within the 512\,MB RAM quota.
    \end{itemize}
\end{itemize}

\section{Essential Terminology and Definitions}
\label{sec:glossary_terms}
% -----------------------------------------------------------------------------

\begin{description}[leftmargin=!,labelwidth=4.5cm]
    \item[Adaptive Signal Control:] Traffic control method where phase timings and cycle splits adapt dynamically in real time based on observed traffic demand rather than fixed pre-programmed schedules.
    \item[Bounding Box ($[x_1, y_1, x_2, y_2]$):] An axis-aligned rectangular region enclosing an object in an image, defined by top-left and bottom-right pixel coordinates.
    \item[ByteTrack:] A tracking algorithm that associates both high-score and low-score detection bounding boxes to recover occluded objects.
    \item[Centroid:] The geometric center of a 2D bounding box, computed as $(cx, cy) = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$.
    \item[Cold Start:] The delay incurred when a cloud container platform (e.g., Render free tier) boots an idle instance upon receiving an incoming HTTP request.
    \item[Confusion Matrix:] A table layout evaluating classification performance, tabulating True Positives ($TP$), False Positives ($FP$), True Negatives ($TN$), and False Negatives ($FN$).
    \item[Deduplication:] Algorithmic filtering ensuring that recurring observations of the same physical vehicle or violation are recorded only once.
    \item[Greedy Bipartite Matching:] An association algorithm that iteratively selects the maximum-weight candidate pair until no remaining pairs satisfy a matching threshold.
    \item[Ground-Plane Homography:] A $3 \times 3$ projective transformation matrix mapping points on the 2D camera image plane to physical 2D ground coordinates in meters.
    \item[Haversine Formula:] An equation giving great-circle geodesic distances between two coordinates on a sphere from their latitudes and longitudes.
    \item[Intersection over Union (IoU):] The ratio of the intersection area of two bounding boxes to their combined union area: $\frac{|A \cap B|}{|A \cup B|}$.
    \item[NMS (Non-Maximum Suppression):] A computer vision technique to filter overlapping redundant bounding boxes predicting the same object.
    \item[Preemption:] An immediate interruption of standard cyclic signal rotations to allocate green right-of-way exclusively to emergency vehicles.
    \item[Provenance:] Metadata documenting the origin, training context, and generation mechanism of data or model inferences.
    \item[Random Forest:] An ensemble machine-learning model constructing multiple decision trees during training and outputting the mode of their class predictions.
    \item[SPA (Single Page Application):] A web application architecture that loads a single HTML page and dynamically rewrites page content via client-side routing.
    \item[YOLO (You Only Look Once):] A single-stage deep neural network object detector that predicts bounding boxes and class probabilities directly from full images in a single forward pass.
    \item[Zustand:] A lightweight, unopinionated client-side state management library for React based on simplified publish-subscribe hooks.
\end{description}

\begin{tcolorbox}[colback=slate!5,colframe=navy,title=\textbf{BENGALURUTRAFFICAI --- ONE-PAGE RAPID REVISION SHEET}]
\small
\begin{itemize}[leftmargin=*]
    \item \textbf{Core Identity:} Intelligent Traffic Management System with Edge Computer Vision (Local CV) and Cloud Demonstration (Hosted Demo) modes.
    \item \textbf{Tech Stack:} Python 3, YOLOv8n, OpenCV, scikit-learn (Random Forest), Flask, React 18, Vite 5, Zustand, Tailwind CSS, Recharts. Deployed on Vercel (frontend) and Render (backend).
    \item \textbf{Detection \& Tracking:} YOLOv8 nano detects COCO vehicle classes (car, bus, truck, motorcycle). \texttt{TrackerManager} associates tracks using greedy IoU ($\theta \ge 0.3$) and preserves occluded tracks for 30 frames.
    \item \textbf{Violations:} Red-light line crossings and wrong-side flow detected via spatial centroid tracking. Events are deduplicated in memory by track ID.
    \item \textbf{Signal Planning:} Dynamic green-time allocation scales with vehicle counts: $G_i \propto N_i$, clamped strictly between 10s minimum and 60s maximum. Emergency preemption forces a 30s priority phase.
    \item \textbf{Machine Learning:} 50-tree Random Forest classifier predicting \texttt{LOW}, \texttt{MEDIUM}, \texttt{HIGH}, \texttt{SEVERE} congestion from count, speed, and hour. Explicitly documented with synthetic provenance.
    \item \textbf{Geospatial Advisory:} Driver portal calculates great-circle distance using the Haversine equation with rigorous input bounds ($-90 \le \phi \le 90$, $-180 \le \lambda \le 180$).
    \item \textbf{Testing \& Stability:} 46 automated regression tests covering API contracts, signal clamping, and spatial boundaries. Frontend coordinates concurrent fetching via \texttt{Promise.all} with graceful cold-start degradation.
\end{itemize}
\end{tcolorbox}

\section{Final Interview Readiness Checklist}
\label{sec:glossary_checklist}
% -----------------------------------------------------------------------------

Before stepping into an interview, verify that you can explain each of the following points clearly without checking notes:

\begin{checklist}
    \item State the 30-second elevator pitch fluently and naturally.
    \item Explain the difference between \texttt{backend/app.py} and \texttt{backend/app\_demo.py} and justify the architectural trade-off.
    \item Write the mathematical formula for IoU and compute a simple 2-box overlap on a whiteboard.
    \item Explain how greedy bipartite matching updates track lifecycles and registers new vehicles.
    \item Explain how violation deduplication prevents double-counting using track-ID sets.
    \item State the minimum (10s) and maximum (60s) green-time clamps and explain why they are critical for traffic safety.
    \item Derive the speed calculation from pixel delta, scale factor, and timestamps, and explain the perspective distortion limitation.
    \item Explain how the React frontend polls the backend using \texttt{Promise.all} and how it handles Render cold starts.
    \item Describe a specific bug you fixed, how you validated the fix, and how your automated test prevents regression.
    \item State all project limitations honestly (uncalibrated homography, synthetic ML training, straight-line Haversine distance, isolated junction scope) and outline your roadmap for future improvements.
\end{checklist}
